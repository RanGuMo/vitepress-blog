# 树
## tree
数据结构

### 树  
树是一种 hierarchical data structure，树由节点组成，节点包含数据元素和指向其他节点的指针。树中的第一个节点称为根节点，根节点之后的节点称为子节点。树中的最后一个节点称为叶子节点。树中的节点可以有任意数量的子节点。


树结构可以用数组表示，数组中的每个元素都是一个节点，数组中的元素索引表示节点的索引，数组中的元素值表示节点的数据。数组中的元素索引的父节点索引为索引除以2的整数部分，子节点索引为索引乘以2和索引乘以2加1。
树结构可以用链表表示，链表中的每个元素都是节点，链表中的元素值表示节点的数据，链表中的元素指针表示节点的子节点。
树结构可以用二叉树表示，二叉树中的每个节点最多有两个子节点，左子节点的索引为索引乘以2，右子节点的索引为索引乘以2加1。
树结构可以用多叉树表示，多叉树中的每个节点可以有多个子节点，子节点的索引为索引乘以子节点数量加1。
树结构可以用树形结构表示，树形结构中的每个节点都有子节点，子节点的索引为索引乘以子节点数量加1。
树结构可以用图表示，图中的每个节点都是节点，图中的每个边表示节点的子节点关系。
树结构可以用树形结构表示，树形结构中的每个节点都有子节点，子节点的索引为索引乘以子节点数量加1。


树结构可以用数组表示，数组中的每个元素都是节点，数组中的元素索引表示节点的索引，数组中的元素值表示节点的数据。数组中的元素索引的父节点索引为索引除以2的整数部分，子节点索引为索引乘以2和索引乘以2加1。
